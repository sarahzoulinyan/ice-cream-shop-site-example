# 🍦 Chilliz

> Landing Page para sorveteria artesanal com troca dinâmica de sabores, formulário de delivery e suporte multilíngue.

🌐 **Website:** https://www.pablogdev.com.br  
🚀 **Demo:** https://pablog-7.github.io/chilliz-ice-cream/

---

## 🎯 Sobre o Projeto

A **Chilliz** é um UI Concept de uma sorveteria artesanal desenvolvido para compor meu portfólio de desenvolvimento front-end. O projeto apresenta uma experiência imersiva com troca dinâmica de sabores que altera a cor de fundo da página, um formulário de delivery integrado e suporte a três idiomas (Português, Inglês e Espanhol).

Desenvolvido com HTML, CSS e JavaScript puro, este conceito demonstra a criação de landing pages envolventes e interativas para o setor de alimentos e bebidas.

## ⚡ Funcionalidades

### 🏠 Hero Interativo

- Título com fonte cursiva e gradiente
- Subtítulo dinâmico que muda com o sabor selecionado
- Descrição personalizada
- Thumbnails com preview dos sabores
- Troca de cor de fundo ao selecionar um novo sabor
- Animação suave na transição da imagem principal

### 🍦 Shop (Vitrine)

- Grid de produtos com 4 sabores
- Cards com glassmorphism
- Imagens dos produtos
- Nome, descrição e preço
- Botão "Adicionar" com feedback visual
- Efeito hover com elevação e escala

### 🛵 Delivery

- Formulário completo para pedidos
- Campos: Nome, Email, Endereço, Sabor
- Validação de campos obrigatórios
- Feedback visual com notificações
- Animação de moto e badge "30 min"
- Partículas flutuantes

### 🌍 Multilíngue

- Suporte a 3 idiomas: Português, Inglês, Espanhol
- Alternância via bandeiras no header e menu mobile
- Tradução de todos os textos da interface
- Atualização dinâmica sem recarregar a página
- Placeholders de formulário traduzidos

### 📱 Experiência Mobile

- Menu hamburger com animação slide-in
- Flags de idioma dentro do menu mobile
- Layout adaptado para telas pequenas
- Formulário responsivo em coluna única

---

## 🎨 Destaques do Design

- **Glassmorphism** - Cards, thumbnails e elementos com blur
- **Troca Dinâmica de Cores** - Fundo muda com o sabor selecionado
- **Tipografia** - Combinação de Lobster (cursiva) e Poppins (moderna)
- **Animações** - FadeIn, Float, Pulse, Drive, Glow
- **Scrollbar Customizada** - Estilização com cores dinâmicas
- **Badge de Entrega** - "30 min" com animação pulsante
- **Ícone de Moto** - Animação de ida e volta
- **Notificações Toast** - Feedback visual para ações do usuário

---

## 📱 Responsividade

- **Mobile** - Otimizado para smartphones (até 480px)
- **Tablet** - Layout adaptado para telas médias
- **Desktop** - Experiência completa em telas maiores
